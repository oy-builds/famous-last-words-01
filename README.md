# Last Breath, Spent on the Weather

A make.fun entry for "Famous Last Words at 1 Percent": the funniest one-line
farewell a phone could say as its battery hits 1 percent.

`main.ts` (Node 22, standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> I dimmed myself to a whisper, kept your boarding pass, your alarm, and your ex's unread text alive — and you spent my last breath checking if it might rain tomorrow.

Run it with `node main.ts`.
